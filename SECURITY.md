# Security Policy

## Supported Versions

This project is a local development tool. Security fixes are applied to the current `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for secrets, API key exposure, or exploitable vulnerabilities. Report privately through the repository owner's preferred security contact.

## API Keys

Do not commit real API keys. Use environment variables or an ignored local `config/api_targets.json` file.

The example configuration only contains environment variable names, never real tokens.
